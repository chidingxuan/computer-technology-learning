# 01 函数参数与可变对象

## 可变对象

Python 中常见的可变对象包括：

- `list`
- `dict`
- `set`

对象创建后，它们内部保存的内容可以改变。

```python
names = ["Alice"]
names.append("Bob")
```

`names` 仍然指向原来的列表对象，只是列表内容发生了变化。

字符串、整数和元组通常视为不可变对象：

```python
name = "Alice"
name = name + " Smith"
```

这里不是修改原字符串，而是创建新字符串，并让 `name` 指向它。

## 默认参数只在定义函数时求值一次

下面的列表不是在每次调用时创建：

```python
def add_item(item, items=[]):
    items.append(item)
    return items
```

Python 执行 `def` 时创建一次默认列表。以后没有传入 `items` 的调用会共同使用它：

```python
print(add_item("a"))  # ["a"]
print(add_item("b"))  # ["a", "b"]
```

推荐使用 `None` 表示“调用时没有提供列表”：

```python
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items
```

这样每次省略 `items` 时都会创建新列表。

## `is None` 和 `== None`

判断是否为 `None` 时，推荐：

```python
if items is None:
    ...
```

`is` 判断是否为同一个对象。`None` 是单例，因此这里正适合使用 `is`。

## 不要误用真假判断

下面的写法会把空列表和“没有传入”混为一谈：

```python
if not items:
    items = []
```

如果调用者有意传入空列表，这段代码也会创建另一个列表。需要区分这两种情况时，应使用 `is None`。
