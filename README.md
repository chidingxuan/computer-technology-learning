# Codex 学习路线

目标：建立 Python 工程能力，并逐步完成可测试、可部署的大模型应用。

## 当前阶段

Python 工程基础

## 学习方式

1. 阅读一小节概念
2. 回答理解题
3. 独立完成代码练习
4. 运行测试并修改
5. 通过验收后进入下一节

## 目录

学习资料按照“学习阶段 → 课次”整理：

```text
01_Python工程基础/
├─ 01_函数参数与可变对象/
├─ 02_模块包与导入/
├─ 03_异常处理/
└─ ...
```

每节课的笔记、Notebook、练习代码和配套文件统一放在该课文件夹中。
