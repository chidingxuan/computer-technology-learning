# Codex 学习路线

目标：建立 Python 工程能力，并逐步完成可测试、可部署的大模型应用。

## 当前阶段

`01_Python工程基础`和`02_Web后端开发`的`03_Pydantic数据模型`已完成，当前正在学习`04_FastAPI工程结构`。

## 学习方式

1. 阅读一小节概念
2. 回答理解题
3. 独立完成代码练习
4. 运行测试并修改
5. 通过验收后进入下一节

新课程的设计、文件结构、讲解深度、作业、测试和验收统一遵循[课程创建规范](./课程创建规范.md)。

教程中首次使用标准库或第三方库函数时，需要说明函数来源、用途、参数含义和返回值。

理解题只能检验前文已经充分讲解并配有示例的知识；出题前需要逐题检查教程覆盖度，不能用题目第一次引入新概念。
