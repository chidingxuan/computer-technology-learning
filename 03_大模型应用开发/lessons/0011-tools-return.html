结果要回答原来的调用

本地查到了数据，模型不会自动看到变量。要把结果放进下一次请求，模型才有机会使用它。

必须保留两段

assistant：tool_calls中有id="call-a"，要求查lib-east
tool：tool_call_id="call-a"，content是执行结果文本

先保留原assistant，再追加tool。不能只发结果，不能把工具名当调用ID，也不能把结果提升成system规则。

对象本课类型/取法
SDK message第三方对象；教师适配前可能用点号访问。
学生assistant消息Python字典，用message["tool_calls"]；参数仍是JSON字符串。
程序执行结果字典，含ok/data或ok/error。
tool的contentjson.dumps(result, ensure_ascii=False)得到字符串。

变化与错误

同一工具被请求两次，call-a查东馆、call-b查西馆，需要两条正确配对的结果。一个失败也要回自己的错误结果，不能只回成功那条。错误ID或漏掉原请求，会破坏协议关系。

assistant有tool_calls时，content可以是None或空字符串，不等于最终空回答。工具结果序列化只是包装，不是事实或安全证明。

嵌套副本

tool_calls又是列表，里面还有function字典，所以只对每条消息做.copy()仍共享内部数据。copy.deepcopy(messages)复制本课JSON形状的嵌套数据，避免新请求改坏旧快照；不把客户端对象一起复制。
