02 / 返回与保存是两回事

HTTP200，不等于应写进成功历史

HTTP层负责接收请求和返回响应；业务status说明本次处理结果；saved说明是否真正提交了消息对。这三件事不能混用。

业务结果
  → answered / complete 且正文非空？
      是：save_pair(cid, question, answer)一次 → saved=true
      否：不提交 → saved=false

save_pair是教师回调，使用同一SQLite事务存user和assistant。第二条失败，第一条也回滚。不把工具请求/结果写进旧库的user/assistant表。

对照

answered＋有效正文可保存；no_answer即使有“资料不足”的文字也不保存。工具查询found=false后模型给出正常解释，可为complete；complete不保证找到记录或事实正确。

参数错误422，会话不存在404，TODO未完成501，模型/存储异常502。不能因HTTP200或正文非空就保存全部结果。数据库历史不会自动进入下一次模型请求。
