01 / 两条路径，一份契约

客户端选路径，不让模型猜路由

用户提交question和mode。mode省略为rag，显式tool走工具；None和额外白名单字段会在HTTP层被拒绝。服务端掌握registry和allowed_names，客户端不能给自己扩大权限。

question + mode
  ├─ rag → retrieve → 第6课answer_question → 原文、生成、引用
  └─ tool → 第7课run_agent → 请求、许可、执行、配对、停止

正常、变化、错误

实验预约问题走rag，有候选才请求模型，sources来自实际证据；room-a设备查询走tool，sources为空，工具结果不是RAG引用。零候选返回no_evidence，不改走另一条路径。

模型异常继续抛给HTTP层，不能伪装成资料不足。本课文字重合检索是真实基线，不冒充Embedding；真实模型演练和离线回归分开保存。
