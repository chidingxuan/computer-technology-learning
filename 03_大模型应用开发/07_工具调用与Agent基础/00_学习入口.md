## 环境：不要再混淆两套.venv

本课可沿用第6课能运行Notebook的Python环境，不需要另建环境。Notebook右上角选当前已装依赖的内核；不要把“终端装过”当成“Notebook已装”。

在本课目录，Windows PowerShell/macOS/Linux均可：

```sh
python -m pip install -r requirements.txt
python -m pip show openai python-dotenv pytest
python -m pytest -q test_agent_tools.py
```

Notebook当前内核若缺包，可在本课目录新格运行`%pip install -r requirements.txt`，必要时重启后从准备格开始。python是当前所选解释器，-m pip使用它的包管理器，-r读取清单。openai接DeepSeek兼容接口；python-dotenv读配置；pytest跑离线测试。教师使用SDK 2.54.0核对接线，Python 3.12/3.14均验证。

## 可选真实观察

见Notebook第2.4节和[真实工具观察记录](真实工具观察记录.md)。开关默认False；手动开启，每运行一次最多两次短请求，可能计费。第一次指定一个只读工具，第二次禁止新工具，目的只是观察协议，不当作自主Agent评估。可复用第一课的本地.env；不打印、不提交密钥。

不要“全部运行”后还留下True开关再反复运行。工具本体只查本地固定字典，不执行Shell或写文件。创建阶段已观察两次请求和一次本地工具执行，无需为了读记录重复请求。
