# 工具调用速查

## 五个时刻

准备工具说明/注册表/许可 → 问模型 → 收到assistant工具请求 → 应用校验并执行 → 原assistant＋tool结果再问模型 → 最终文字或继续。

工具定义不是实现，模型请求不是授权。应用执行函数；模型看不到本地变量，必须回传结果。

## 字段与对象

| 名称 | 类型与职责 |
|---|---|
| tools | list[dict]，给模型的名称/说明/参数Schema |
| registry | dict[str, Callable]，名称到真实Python函数 |
| allowed_names | set[str]，本次执行许可 |
| call.id | 协议字段；学生字典用call["id"]，不是SDK点号 |
| function.arguments | JSON字符串；validate_arguments后才是参数dict |
| tool_call_id | tool消息中原样复制对应请求id，不用工具名代替 |
| tool.content | 结果文本；本课json.dumps(result, ensure_ascii=False) |
| deepcopy(messages) | 嵌套消息副本，不复制SDK客户端，不是沙箱 |
| operation_key(call) | 名称＋参数内容；忽略ID和JSON排版空格 |

## 本课结果，不与第06课或HTTP混用

- 工具：ok=True/data；拒绝或失败为ok=False/error。
- unknown_tool：未注册；not_allowed：已注册但未获准；bad_arguments：教师参数校验拒绝。
- tool_timeout/tool_failed：工具执行异常，不等于业务查询found=False。
- Agent：complete（返回最终文字）、step_limit、repeated_call；前者不证明事实正确。
- model_calls：ask正常返回次数；tool_calls：execute_call处理请求数，含拒绝与失败，不是成功执行次数。
- ask抛异常：原样向外传播，不重试、不伪装不知道。

## 停止检查

| 情况 | 本课策略 |
|---|---|
| 预算0 | 不问模型 |
| 最后一次返回最终文字 | 正常complete |
| 最后一次仍要工具 | step_limit；不启动、不提交半轮 |
| 仍有预算，同批/跨轮同名同参数 | 整批repeated_call；不执行前半批 |
| 不重复，有预算 | 全部请求处理并按ID回传后再问 |

不同参数不是重复。全部保留原assistant请求；同一次多个调用必须各有tool结果，即使某个失败。只读白名单不是沙箱；步骤上限不是墙钟超时；禁止任意Shell和写操作。
