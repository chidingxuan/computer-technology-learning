# 向量检索：一页速查

检索交付资料，不交付生成答案。术语定义在Notebook首次出现处；本页用于完成练习后查阅。

```text
建库：资料文本 → 兼容的Embedding文档编码 → 文本/来源/向量一起保存
查询：问题文本 → 兼容的Embedding查询编码 → 余弦打分 → 降序Top-K → 阈值筛选
下课才接：合格资料＋问题 → 聊天模型 → 有来源的回答
```

本课使用手工教学向量，不调用真实Embedding模型；同维度不保证同空间，不能混用不兼容模型。真实模型需遵循查询/文档编码设置，换模型通常要重建资料向量。

| 名称 | 输入→输出 | 本课约定 |
|---|---|---|
| cosine_similarity | 两个非空数字列表→float | 点积÷两长度乘积；不同维度、任一零向量抛ValueError |
| search_chunks | 查询向量、chunks、top_k→hits | 分数降序后取前K；同分保留输入顺序；K=0返回[] |
| filter_hits | hits、min_score→新列表 | score>=门槛；保留字段与顺序；允许[] |

数学：点积=`sum(a_i*b_i)`；长度=`sqrt(sum(a_i*a_i))`。同向1、垂直0、反向-1；正比例放大不改变余弦。分数不是概率或事实正确率；零方向得分不能自行猜成1。

语法：`zip(a,b)`配对、长度不等会默认截断；`sqrt(x)`来自math；`sorted(records,key=取分函数,reverse=True)`返回新列表且稳定；`[:k]`取前k项，k=0为空。

资料：`id:str / text:str / source:str / vector:list[float]`。
候选：`id:str / text:str / source:str / score:float`，不含vector。
score由检索代码计算，不由用户填写；本课无HTTP请求，字段名均为教学约定而非Python关键字。

| 现象 | 优先检查 |
|---|---|
| 向量变长分数暴涨 | 只算了点积，没除长度 |
| 最相关资料漏掉 | 是否先截输入再排序 |
| 0条却返回全部 | 使用的是`[:0]`还是`[-0:]` |
| 改换模型排序奇怪 | 维度相同不等于空间兼容 |
| 每次总有“答案” | Top-K只是候选；门槛后允许空列表 |
| 来源与正文错位 | 排序整条候选，不只排序分数 |

阈值须由真实任务样例调整，0.8仅是教学例子。高分仍可能不含答案、过时或不正确；本课不评估真实模型质量。

来源：[语义检索](https://sbert.net/examples/sentence_transformer/applications/semantic-search/README.html)、[余弦公式](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.pairwise.cosine_similarity.html)、[稳定排序](https://docs.python.org/3/howto/sorting.html)。核对：2026-10-14。
