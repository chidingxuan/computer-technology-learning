## 安装与执行

先在本课目录运行 `python -m pip install -r requirements.txt`；默认Notebook不联网、不下载、不计费。Notebook安装可用 `%pip`，它针对当前内核。

真实Embedding使用FastEmbed与中文BGE模型，已获你授权下载，缓存位于仓库外。复跑步骤见Notebook 1.3；可选依赖在 `requirements-semantic.txt`。终端实验只编码检索，不调用DeepSeek；Notebook的两个实验开关均默认False。

若想用隔离环境，先在本课目录 `python -m venv .venv`。Windows用 `.venv/Scripts/python.exe`，macOS/Linux用 `.venv/bin/python` 替代下面的python：

```powershell
python -m pip install -r requirements-semantic.txt
python semantic_search.py --download
python semantic_search.py
```

首次下载后不加--download，使用现有缓存；若提示实验未完成，按顺序检查：该解释器是否已安装fastembed → 首次下载是否成功 → 是否换设备/系统用户导致缓存不可用。不要把HF_TOKEN或DeepSeek密钥粘贴到Notebook。公开模型下载的未登录限速警告不是错误。

真实DeepSeek仅在Notebook 2.3手动开关后调用一次：发送本课虚构资料，最大输出240token、超时30秒、不自动重试。它是生成，不是Embedding。可以直接复用第一课.env的密钥。不要自动上传任何.env、虚拟环境或模型。
