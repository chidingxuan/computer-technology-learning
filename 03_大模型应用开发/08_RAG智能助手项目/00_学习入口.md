## 环境与运行

本机已创建本课独立.venv，旧课环境不改动。换设备后在本课目录：

```sh
python -m venv .venv
```

macOS/Linux：

```sh
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m pytest -q test_project_support.py
.venv/bin/python -m uvicorn project_api:app --host 127.0.0.1 --port 8008
```

Windows PowerShell把解释器路径换为`.venv/Scripts/python.exe`。Notebook当前内核缺包时运行`%pip install -r requirements.txt`并重启；不要把另一个终端装过当成内核可用。fastapi/uvicorn提供服务，pydantic校验，httpx测试和发送本地HTTP，starlette限制<1保持已验证TestClient组合，openai/python-dotenv复用真实模型接线，pytest离线测试。

浏览器打开 http://127.0.0.1:8008/docs ：先POST /conversations创建会话，再使用**新增**POST /assistant/conversations/{id}/messages；旧无/assistant前缀的发送接口仍用模拟回复。真实配置优先本课.env，否则沿用第7课配置；.env.example只含占位符，不复制密钥到Notebook。

当前教师测试可能出现依赖内部的BlockingPortal弃用警告，不是测试失败；已验证40项回归及真实服务。具体版本和限制见课程设计与验收，不需要因此修改学生代码。

## 学习顺序

1. Notebook第1组：看证据怎样进入请求，分别跑可选真实RAG/工具观察，完成园区路径练习。
2. 第2组：看HTTP自动校验、默认mode、错误码和原子提交；完成预测与保存练习。
3. 第3组：区分代码正确与真实答案质量，完成诊断练习。
4. 只补assistant_project.py的3个TODO；不修改教师接线、冻结问题或旧课答案。
5. 完成后运行28项作业测试、12项教师回归；保持服务启动，另一个终端运行`.venv/bin/python run_evaluation.py --live`。
6. 做5题理解题；第二天新建空白草稿重建关键流程，正式答案不清空。

每次运行--live会再跑全部6例，可能有多次模型调用。默认不重试，不为凑成绩改题或挑结果。新项目单次问题处理，不承诺数据库历史自动进入下一次模型上下文。没有向量库、用户登录、多租户、任意代码执行或生产部署。
