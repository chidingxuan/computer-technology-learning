# 项目闭环速查

| 时刻 | 主体 | 输入→输出 |
|---|---|---|
| HTTP入站 | FastAPI | JSON→AskBody；缺字段/非法mode/额外字段422 |
| 检查会话 | 教师路由 | conversation_id→存在/404；不存在不问模型 |
| 选路径 | run_request | question/mode/回调→六键公开结果 |
| RAG | 第6课answer_question | hits→原文进入user→生成→引用检查；零hits零模型 |
| tool | 第7课run_agent | ask→许可/参数/配对→有上限的循环 |
| 提交 | save_exchange | answered/complete且非空→save_pair一次→bool |
| 事务 | 教师store_pair | user/assistant同事务，失败回滚两条 |
| 评估 | evaluate_case | 冻结预期/result→case_id/passed/failures |

公开结果：`mode/status/answer/sources/model_calls/tool_calls`；HTTP另加`saved`。RAG保留第6课状态；工具保留complete/step_limit/repeated_call、sources=[]；不公开内部messages。

模式：省略rag，显式tool可用，None不合法。max_steps省略4、显式0零请求、None不合法。db_path省略/None使用本课数据库，测试可传临时Path。

HTTP：200是成功返回业务结果，不保证answered或保存；201创建会话；404会话不存在；422请求不符；501TODO未写；502模型/存储失败，不当作资料不足。

评估失败顺序：status→answer（全部片段）→sources（ID集合精确相等）→budget（model_calls≤上限）。空must_include无正文约束；空expected_source_ids要求无来源。关键词/ID通过不自动证明事实。

测试：`python -m pytest -q test_assistant_project.py test_project_support.py`。服务：`python -m uvicorn project_api:app --host 127.0.0.1 --port 8008`。真实固定集：`python run_evaluation.py --live`，默认不执行，重复运行会重新计费。

排错：501先补作业1/2；502查配置/联网/额度/存储；200但saved=False先查业务状态；有引用但答错对照原文，不先改检索算法。旧POST /conversations/{id}/messages是模拟回复；新接口带/assistant前缀。
