工具协议一页速查

模型提议，应用检查与执行；结果进入下一次消息后，模型才知道。

system规则 → user问题
→ assistant {tool_calls:[{id:"c1",function:{name,arguments:JSON文本}}]}
→ tool {tool_call_id:"c1",content:JSON结果文本}
→ 再问模型 → assistant最终文字或新调用
检查本课要求
许可注册与获准分开；参数必须校验，不使用eval。
配对保留原assistant；每个调用一个tool结果，按原ID、原顺序；失败也回传。
快照deepcopy复制嵌套列表/字典；SDK对象由教师适配为字典。
预算max_steps数模型请求。最后一次若仍要工具，不执行新批次；最终文字可接受。
重复名称＋参数内容，不按调用ID；同批和跨轮都先检查，整批阻止。
异常工具异常变ok=False；ask异常向外传播，不改成不知道、不自动重试。

model_calls是模型调用次数；tool_calls是处理请求数，包含拒绝/失败，不是成功执行次数。complete不证明事实正确；次数预算不强制终止阻塞函数；只读工具与虚拟环境不是安全沙箱。
