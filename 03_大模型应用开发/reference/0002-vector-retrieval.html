向量检索：工作速查

建库：文本 → 文档编码 → 原文＋来源＋向量
查询：问题 → 查询编码 → 逐条余弦 → 降序Top-K → 门槛 → 候选资料

本课是手工教学向量；真实查询与资料须使用兼容的模型和编码配置。同维度不保证同空间；高分不证明事实正确；不把新概念定义当作学习者已经理解。

计算/操作结论
点积对应分量乘积之和
长度各分量平方和开根
余弦点积÷两长度乘积；同向1、垂直0、反向-1
零向量/不同维度本课抛ValueError，不静默截断
Top-K先排序后取；0为空；同分保留输入序
门槛score≥min_score；允许没有依据

接口和数据

cosine_similarity(a, b) → float
search_chunks(query_vector, chunks, top_k) → list[dict]
filter_hits(hits, min_score) → list[dict]

资料含id/text/source/vector；候选含id/text/source/score。向量用于计算，原文用于后续阅读，来源用于追溯；score不是概率。筛选不改分数、不补造候选。作业输入保证符合类型，不加无关防御。

排错

分数随正比例放大而增大：检查分母。最相关资料漏掉：检查先截后排。正文与来源错位：检查是否只排序分数。门槛后总非空：检查是否硬留第一条。更换模型后结果异常：核对空间与编码配置。
