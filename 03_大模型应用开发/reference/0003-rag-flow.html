证据请求检查学习入口

RAG：两条时间线，三道关

建库：原文 → 完整段落＋来源 → 文档编码
提问：查询编码 → 检索 → 带原文生成 → 结构 → 引用 → 事实
                       └ 无候选：不请求，资料不足
对象/状态本课固定含义
id/text/source/score编号/原文/原位置/检索分；分数不等于概率
system / user固定规则 / 问题与不可信证据数据
citations / sources模型自报ID / 程序从本次证据取回的来源
no_evidence / no_answer无候选零调用 / 有候选但事实不足
invalid_citations / answered引用空或未知而拒绝 / 引用程序关通过，事实仍需核对

没找来 → 检索；送对却说反 → 生成；没有记载 → 不编造。语义编码也会漏检，Top-K不能保证资料够用。

结构合法 ≠ 引用存在 ≠ 原文支持。角色隔离不保证防注入。
