# 术语表：大模型应用开发

后续课程沿用本表。不同协议或对象不能因为名称相似而混用。

| 术语 | 固定含义 |
|---|---|
| JSON解析 | json.loads将JSON文本变为Python对象 |
| 字段校验 | Pydantic按字段类型和约束验证数据，不证明事实来源 |
| JSON Schema | 可传递的结构规则，不是具体记录 |
| model_validate | 检查输入并创建Pydantic实例 |
| model_dump | 从实例导出字典 |
| model_json_schema | 从模型类导出规则字典 |
| history / 已保存历史 | 本课：过去成功完成的user/assistant轮次 |
| 轮次 | 本课：一条user和一条assistant |
| messages / 请求快照 | 本次发送的规则、所选历史和当前问题 |
| 上下文窗口 | 一次模型处理的token预算 |
| delta / 增量正文 | 本次新增片段，不是累计全文 |
| buffer / 临时正文 | 收到后累积用于显示，还未提交 |
| chunk / 原始流片段 | SDK逐项返回的对象，可能带正文或结束原因，不保证按字或句划分 |
| finish_reason / 结束原因 | 服务端响应字段；本课stop为正常结束，length为长度截断 |
| 适配 / 接线 | 把外部SDK对象转换成本课kind/text事件，不代替学生收集或提交逻辑 |
| done | 本课规范化的明确正常完成信号 |
| complete | 本次正文已确认正常完成，不证明业务内容正确 |
| incomplete | 未确认正常完成或明确失败；含真实length转换后无终止事件的耗尽 |
| failed | 收到明确失败信号；真实接线可将捕获的网络异常转换为error |
| 提交成功轮次 | complete且正文非空白时，把user+assistant加入新history |

status和data沿用上一课应用结果命名；本课流结果使用status/text描述文本，不是工单status/data，也不是HTTP状态码。

## 第07课协议词汇（已定义不等于已掌握）

| 术语 | 固定含义 |
|---|---|
| 工具定义tools | 给模型的功能和参数说明，不是Python函数本体 |
| registry / 注册表 | 名称到真实函数的映射；注册不等于本次获准 |
| allowed_names / 执行白名单 | 调用方本次明确批准的工具名集合 |
| tool_calls / 工具调用请求 | assistant响应中的请求列表，不表示函数已经执行 |
| function.arguments | 模型提供的JSON字符串，进入函数前由应用解析校验 |
| tool_call_id | tool结果消息复制对应请求id，不能用工具名代替 |
| 工具结果 | 程序执行后生成的ok/data或ok/error，序列化进tool.content |
| 操作签名operation_key | 本课以名称和参数内容识别重复，不按调用ID |
| 第07课complete | 循环拿到最终文字，不证明工具成功或事实正确 |
| step_limit / repeated_call | 本课预算/重复停止状态，不是HTTP状态或SDK内建拦截 |
| 第07课model_calls / tool_calls计数 | 分别为ask正常返回次数、execute_call处理请求数；后者含拒绝和失败 |
